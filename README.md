# Viga Hardjanto — Portfolio

Personal portfolio of Viga Laksa Hardjanto, showcasing work in technology, research, and education. The site also features selected experience, a downloadable CV, and a video from the Hardj Bersaudara YouTube channel.

## Project structure

| File                          | Purpose                       |
| ----------------------------- | ----------------------------- |
| `index.html`                  | Page content and structure    |
| `styles.css`                  | Styling and responsive layout |
| `script.js`                   | Navigation behavior           |
| `viga-portrait.jpg`           | Profile photograph            |
| `teaching-at-binus.jpg`       | Teaching photograph           |
| `CV_Viga_Laksa_Hardjanto.pdf` | Downloadable CV               |

## Preview locally

Open `index.html` in a browser or use a local server such as the VS Code Live Server extension.
